Commands

Every slash command Shockwave registers, grouped by what part of the night it handles. Parameters marked optional have a default and can be left out.

Team setup

Run these once per server, or whenever you want to reset a session.

/set-team-channels setup

Names the two voice channels teams get moved into. Creates them if they don't already exist on the server.

ParameterTypeDescription
team1stringName for the first team's voice channel.
team2stringName for the second team's voice channel.
/set-team-size setup

Sets how many players make up one side. Used when notifying people how big the game is.

ParameterTypeDescription
sizechangeintegerNumber of players per team.
/clear setup

Wipes the current teams and draft state so you can start a fresh session. Channel names, tournament data, and player elo/economy are kept unless you explicitly clear them too.

ParameterTypeDescription
clear_channelsboolean, optionalAlso forget the saved team channel names.
clear_tournamentboolean, optionalAlso clear tournament bracket data.
clear_eloboolean, optionalResets every player's elo back to 1000 for this server — balance, wins/losses, and gold are untouched. Server-wide, so it asks for confirmation before it runs (see below).
clear_economyboolean, optionalWipes every member's stats for this server entirely — balance, elo, game record, betting record, and gold wagered/won/lost. Also server-wide and confirmation-gated; if both this and clear_elo are set, this one wins since it already includes an elo reset.
Both flags require confirmation. Since clear_elo and clear_economy reset data for every player in the server, neither runs immediately — Shockwave posts a warning with "Confirm reset" / "Cancel" buttons, and only the member who ran /clear can click them. The prompt expires after 30 seconds with nothing changed if it's ignored.

Team formation

Two tracks: casual games just organize a roster, ranked games also balance and track elo.

Casual vs. ranked — the actual difference. Every game, casual or ranked, still runs through /start to move players and open betting, and still updates each player's Game Record (win/loss) when a winner is reported. The only thing ranked adds: teams are split by current elo instead of pure random/draft order, and elo itself only ever moves for games built with /ranked or /ranked-captains. A casual game — /make-teams or plain /captains — never touches anyone's elo, win or lose. Pick the track when you build the roster; everything downstream (/start, betting, reporting the winner, /return) works identically either way.

Casual

Organizes a roster for the night. Betting still works — elo never moves.

/make-teams casual

Randomly splits everyone in your voice channel into two even teams and posts the roster. Optionally assigns a lane to each player. Doesn't move anyone — run /start once you're happy with the teams to move everyone and open betting.

ParameterTypeDescription

Setting up a casual game

01

Get everyone into one voice channel.

02

Build the roster: /make-teams for an instant random split, or /captains + /choose for a live draft.

03

/start moves everyone into their team channels and opens betting.

04

React 1️⃣/2️⃣ to report the winner. Bets pay out and Game Record updates — elo is untouched.

Ranked

Same idea as casual, but the split is elo-aware and elo is on the line.

/ranked ranked

Splits your voice channel into two roughly elo-balanced teams — same "build the roster, then /start" flow as /make-teams, but the split is weighted by everyone's current elo (with some randomness so it isn't the exact same optimal matchup every time) instead of being fully random.

How the split works. Each player's elo gets a random nudge, then teams are drafted strongest-to-weakest in a snake pattern (side A, side B, side B, side A, …) so team sizes stay even and the top players don't all land on one side.
/ranked-captains ranked

Exactly /captains — same parameters, same draft with /choose — except the resulting game has elo tracked when the winner is reported.

ParameterTypeDescription
captain_1member, optionalFirst captain. Required unless use_random is set.
captain_2member, optionalSecond captain. Required unless use_random is set.
use_randomboolean, optionalPick two captains at random from the voice channel instead.

Setting up a ranked game

01

Get everyone into one voice channel. New players start at 1000 elo automatically — nothing to set up ahead of time.

02

Build the roster: /ranked for an elo-balanced instant split, or /ranked-captains + /choose for a live draft that's still marked ranked.

03

/start moves everyone into their team channels and opens betting — identical to the casual flow.

04

React 1️⃣/2️⃣ to report the winner. Bets pay out, Game Record updates, and elo shifts for every rostered player — more for beating a stronger team, less for beating a weaker one.

05

Reacted with the wrong result? /report-correct-winner undoes the wrong elo/payouts and re-applies them correctly — admin-only.

Ending a ranked game early. /return works exactly like it does for a casual game — it refunds any open bets and moves everyone back. Since elo only ever changes when a winner is actually reported, ending a ranked game with /return before that happens leaves elo completely untouched, same as if the game had never been played.

Voice channel ops

Moving people around without dragging them by hand.

/start voice

Moves the current rosters into their team channels and kicks off the game. Remembers the channel everyone started in, so /return knows where to send them back. Also opens a one-minute betting window on the match — see Betting & economy below.

/return voice

Pulls both team channels — including anyone spectating — back into the original voice channel. If the game's winner hasn't been recorded yet, any open bets are automatically refunded.

/notify voice

DMs one server member a one-time invite link to your voice channel.

ParameterTypeDescription
membermemberWho to invite.
/notify-role voice

Same as /notify, but DMs everyone holding a given role.

ParameterTypeDescription
roleroleThe role to notify.

Betting & economy

Every server member has a gold balance. Bet it on who wins the current game.

How a betting round works. Running /start opens betting for 60 seconds — the bot stays fully responsive to every other command during that window. Once it closes, Shockwave posts a message asking which team won and reacts to it with 1️⃣ and 2️⃣ itself, so reporting the result is a single click. The first valid reaction from anyone in the server records the winner, pays out bets, updates everyone's game record (and elo too, for /ranked and /ranked-captains games), and moves both teams back to the original channel automatically — no separate /return needed. If /return is used before a winner is reported, every bet on that round is refunded instead. Reacted with the wrong result? /report-correct-winner fixes it after the fact.
/wager betting

Bets gold on one team winning the current game. Only works while betting is open, only one bet per player per game, and you can't bet on a game you're actually playing in.

ParameterTypeDescription
amountintegerHow much gold to wager. Must not exceed your balance.
teamchoiceTeam 1 or Team 2 — whoever you think wins.
Payouts favor the underdog. Winners split the losing side's entire pool proportional to their own bet, on top of getting their wager back. A bet on the team fewer people backed pays out more than the same-sized bet on the heavily-favored side.
/wager-against betting

Challenges another player to a heads-up gold wager, completely separate from the team-game betting above — no /start or current game required.

ParameterTypeDescription
membermemberWho to challenge. Can't be yourself or a bot.
amountintegerHow much gold each side stakes. Must not exceed your balance.
How it plays out. Shockwave posts a message mentioning the challenged player and reacts with ✅ — only they can react to accept. Nothing is held from either side until they do; on accept, both players' gold is escrowed and a new message goes out asking who actually won, reacted with 🔵 (challenger) and 🔴 (challenged player) automatically. The first valid reaction from anyone in the server records the result and pays the full pot to the winner — same "first reaction wins" behavior as reporting a team game's winner. If either player can no longer cover the amount by the time it's accepted, the wager is cancelled instead of running.
/daily betting

Claims 1000 free gold. Once per calendar day, per player.

/stats betting

The full picture for one player: elo (shown with a League-style rank), actual in-game win/loss record (separate from betting), betting record, balance, and net gold won or lost overall — all in one embed.

ParameterTypeDescription
membermember, optionalWhose stats to look up. Defaults to you.
Elo is ranked-only, per-server. Every player starts at 1000. Elo only changes for games formed with /ranked or /ranked-captains — /make-teams and regular /captains games update the Game Record above but never touch elo. When it does update, the size of the change is based on the average rating on each side — beating a higher-rated team gains more than beating a lower-rated one.
Elo shows an emoji rank alongside the number, the same way League does — nine tiers, each spanning 250 elo, with the 1000 starting elo landing everyone in Platinum by default. Iron through Diamond also break down into four divisions (IV lowest, I highest) the same way League's do; Master and up just show the tier, same as League switching to raw LP once you're that high:

/report-correct-winner admin

Fixes a misreported winner for the most recently resolved game — undoes the wrong payouts, win/loss records, and elo changes, then re-applies all of it for the correct team. Requires the Manage Server permission.

ParameterTypeDescription
teamchoiceThe team that actually won.
