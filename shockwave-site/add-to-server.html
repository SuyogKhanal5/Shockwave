Get started

Add Shockwave to your server

Inviting the bot is a standard Discord OAuth flow: generate an invite link with the right scopes and permissions, open it, and pick your server. This takes about two minutes.

What you'll need

Manage Server permission

On your own Discord account, for the server you're adding the bot to — Discord won't let you authorize a bot invite otherwise.

The bot's Client ID

From the Developer Portal application for the Shockwave instance you're inviting — yours if you're self-hosting, or the operator's if you're not.

Generate and open the invite link

01

Open the Developer Portal

Go to discord.com/developers/applications and select the Shockwave application.

02

Open the OAuth2 URL Generator

In the sidebar, go to OAuth2 → URL Generator.

03

Check two scopes

Under Scopes, check bot and applications.commands. The second one is what makes slash commands like /make-teams show up at all.

04

Check the bot permissions

A Bot Permissions panel appears below. Check the five permissions in the table further down this page — Discord builds the invite URL for you as you check boxes.

05

Copy the generated URL

Scroll down and copy the Generated Link. It looks like this, with your own client ID in place of the placeholder:

https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=17828944&scope=bot%20applications.commands
06

Open it and pick your server

Paste the link into your browser, choose your server from the dropdown, and hit Authorize. Discord will ask you to confirm the permissions before it finishes.

Permissions, and why each one is needed

Shockwave asks for six permissions — nothing broader than what its commands actually do.

PermissionNeeded forWhy
View Channels All commands The bot has to see a voice channel to know who's in it.
Connect /make-teams, /captains Discord only exposes voice channel membership to accounts that could join the channel.
Move Members /start, /return Both commands work by moving players between voice channels directly.
Manage Channels /team-set-channels Creates the two team voice channels automatically if they don't already exist.
Add Reactions /start The bot reacts with 1️⃣ and 2️⃣ on the winner-report message so recording a result and paying out bets is a single click.
Send Messages Every command Posts confirmations, team embeds, and error messages back into the channel.

Verify it worked

Bot shows up in the member list

Shockwave should appear online in your server's member sidebar right after authorizing.

Slash commands autocomplete

Type / in any channel — Shockwave's commands should appear in the picker.

Commands not showing up? This build syncs commands to one specific server (guild) ID, set in the bot's own code — not automatically to every server it joins. If you're inviting a shared/hosted instance, ask whoever runs it to add your server's ID. If you're running your own copy, see step 6 of the self-hosting guide to point it at your server.
